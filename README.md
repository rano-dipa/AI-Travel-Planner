# AI Travel Planner

**AI Travel Planner is a multi-agent AI system that transforms simple travel requests into personalized trip plans.** Users can describe their destination, travel dates, budget, and interests, while specialized AI agents collaborate to research destinations, gather relevant information, generate itineraries, and refine recommendations. The system uses a graph-based workflow to coordinate agents and manage shared state throughout the planning process.

Built with Python and LLM-powered agents, the project follows a modular architecture consisting of specialized agents, reusable chains, shared state management, external tool integrations, and workflow orchestration. The project is currently under active development, with plans to expand its capabilities and introduce additional travel planning features.
